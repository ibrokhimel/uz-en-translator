# Uzbek style guide (general / web content)

## Register
- **Neutral/formal (default for articles, news, instructions):** *siz*, full verb forms, literary vocabulary, *-moqda* acceptable.
- **Conversational (casual blogs, social posts, chats):** shorter sentences, everyday words (*zoʻr*, *rosa*, *hozir*), *-yapti* forms, contractions in speech are fine only when quoting speech. Still *siz* unless the source is clearly intimate or slang.
- **Sen:** friends, children, song lyrics, brand voices that deliberately use it. Use consistently once chosen.

## Native word vs. Russian loanword
Prefer the native or established Uzbek word in neutral writing. Russian forms are fine in quoted speech or very casual text.

| Avoid (Russian loan) | Prefer |
|---|---|
| problema | muammo |
| vopros | savol |
| rezultat | natija |
| informatsiya | maʼlumot |
| aktual | dolzarb |
| effektiv | samarali |
| analiz | tahlil |
| protsess | jarayon |
| sistema | tizim |
| spisok | roʻyxat |
| uspex | muvaffaqiyat |
| konechno | albatta |
| pozdravlyayu | tabriklayman |

Established international words stay: *internet, kompyuter, telefon, sayt, kontent, marketing, startap, video, onlayn*.

## Numbers
- Thousands separator: space — *1 250 000*.
- Decimal separator: comma — *3,5 foiz*.
- Percent: *25 foiz* in running text, *25%* in tables and headlines.
- Ordinals: number + hyphen + suffix — *5-sinf*, *2-oʻrin*, *21-asr*.
- Counting words: *ta* after numbers for countable items in speech and web text — *uchta kitob*; formal text may use *uch kitob*.

## Dates and time
- Full: *2026-yil 7-noyabr* (year with *-yil*, day with hyphen before the month name).
- Short: *07.11.2026* (day.month.year).
- Months and weekdays are lowercase: *yanvar, fevral, mart, aprel, may, iyun, iyul, avgust, sentabr, oktabr, noyabr, dekabr*; *dushanba, seshanba, chorshanba, payshanba, juma, shanba, yakshanba*.
- Time: 24-hour, colon — *14:30*.

## Currency and units
- *soʻm* (not *sum* or *som*). Amounts: *150 000 soʻm*.
- Foreign currency: *100 AQSh dollari*, *50 yevro*; *$100* acceptable in headlines.
- Metric units: convert imperial units when the reader needs to picture them (miles → km, °F → °C), and say so in translator notes.

## Punctuation
- Quotes: use “…” or «…» and stay consistent within a text. Inner quotes: the other style.
- Dash between subject and nominal predicate when the linking verb is omitted: *Toshkent — Oʻzbekistonning poytaxti.*
- Comma after introductory words: *Menimcha, …*, *Afsuski, …*, *Albatta, …*.
- No space before ? ! : ;

## Capitalization
- Headlines and titles: sentence case — only the first word and proper nouns are capitalized. Not English Title Case.
- Organizations: first word and proper nouns — *Oʻzbekiston Respublikasi Prezidenti*, *Toshkent davlat universiteti*.
- Nationalities and languages are lowercase: *oʻzbek tili*, *ingliz*.

## UI strings and instructions
- **Buttons, menu items, tabs:** verbal noun (*-sh / -ish*), no ending: *Saqlash* (Save), *Bekor qilish* (Cancel), *Roʻyxatdan oʻtish* (Sign up), *Kirish* (Log in), *Chiqish* (Log out), *Yuklab olish* (Download), *Sozlamalar* (Settings).
- **Instructions to the user:** polite imperative *-ing*: *bosing*, *kiriting*, *tanlang*, *yuklab oling*.
- **Gestures:** tap / click → *bosing*; double-tap → *ikki marta bosing*; swipe → *suring*; long-press → *bosib turing*; drag → *sudrab olib boring*.
- **Referring to a button in a sentence:** quote it in the same styling as the source and add *tugmasi*: *Roʻyxatdan oʻtish* *tugmasini bosing*.
- Translate the label the same way everywhere it appears. Keep labels short; UI space is limited.
- **Common UI words:** photo → *rasm* (UI default; *surat* in prose, *foto* only in brand names); feature → *imkoniyat* in user-facing text, *funksiya* in technical docs; version → *versiya*; update (verb) → *yangilamoq*, (noun) → *yangilanish*; settings → *sozlamalar*; notifications → *bildirishnomalar*.

## Names
- Uzbek names in English: use the person's own established spelling if known (passport, signature, website), and for legal text ask. Otherwise keep the Uzbek Latin spelling and write oʻ/gʻ with a plain ASCII apostrophe, which English systems handle: *Gʻulom* → *G'ulom*, *Oʻtkir* → *O'tkir*. Don't invent anglicised forms like *Ghulom*. Drop the apostrophe (*Gulom*) only if the user asks.
- English names in Uzbek: keep the original Latin spelling for brands and people (*Apple*, *Elon Musk*) and attach suffixes directly: *Applening*, *NASAning*. After numbers use a hyphen: *2026-yilda*.
- Countries and cities: use the established Uzbek form — *AQSh*, *Buyuk Britaniya*, *Germaniya*, *Rossiya*, *Xitoy*, *Yaponiya*, *Turkiya*, *Qozogʻiston*, *Moskva*, *London*, *Nyu-York*.
